# Cc SNS Hub

Cc が運用するクライアント（想定 7 社）の **Instagram / YouTube / X / TikTok** の数字を 1 か所に集め、
**月次レポートをボタン 1 つ（または毎月 1 日に自動）で作成する** Cc 社内専用システムです。

Statusbrew の「組織 → クライアント → SNS アカウント」という構成を参考に、
Cc の用途（数字管理と月次レポート）に絞って作っています。Statusbrew のサービスやコードは使っていません。
**Google Apps Script（GAS）＋ Google スプレッドシートで動くため、サーバー代は 0 円**です。

---

## できること

| 機能 | 内容 |
|---|---|
| パスワードログイン | Cc の共通パスワードを知っている人だけが入れる。5 回間違えると 15 分ロック。ログインは 6 時間有効 |
| 4 媒体の自動取得 | 毎朝 6 時に全クライアントのフォロワー・投稿・再生/表示・いいね等を取得してスプレッドシートに蓄積 |
| ダッシュボード | 全社の合計と、クライアントごとの 4 媒体の数字・増減を一覧表示 |
| クライアント詳細 | 媒体別の月次表（前月比・エンゲージメント率）、フォロワー推移グラフ、直近投稿一覧 |
| 視聴者属性 | 年齢層・性別・フォロワー/フォロワー外の割合を媒体別に表示。YouTube は投稿（動画）ごとにも表示。レポートにも「見ている人の属性」として反映 |
| 月次レポート | **固定指示 1 つ**で、提出できる品質のレポートを作成 → Google ドキュメントに保存 |
| Claude ＋ ChatGPT 連携 | 推奨設定では ChatGPT が数字から分析メモを作り、Claude がそれを踏まえて清書。片方だけで作る設定も可 |
| 月初の自動作成 | 毎月 1 日 8 時に、前月分のレポート下書きを全社分作って完了をメール通知 |
| AI に質問 | 例：「来月の投稿テーマ案を 5 つ」など、そのクライアントのデータを踏まえて回答 |
| 手入力 | API を使わない媒体（例：X）も、数字を入力すればレポートに反映 |

## 構成

```
ブラウザ（Cc 社員）
   │  共通パスワードでログイン
   ▼
Google Apps Script（Web アプリ）── Script Properties（パスワードのハッシュ・API キー）
   │                         │
   │ 毎朝 6 時 / 毎月 1 日     ├─ Instagram Graph API（Meta）
   ▼                         ├─ YouTube Data API v3
Google スプレッドシート       ├─ X API v2（任意）
（Clients / Snapshots /      ├─ TikTok Display API
  Posts / Reports / Logs）    ├─ Claude API（Anthropic）
   │                         └─ ChatGPT API（OpenAI）
   ▼
Google ドライブ「Cc SNS Hub 月次レポート」フォルダ（Google ドキュメント）
```

| ファイル | 役割 |
|---|---|
| `src/Config.gs` | 定数・シート定義・設定 |
| `src/Auth.gs` | パスワード認証・セッション |
| `src/Store.gs` | スプレッドシートの読み書き |
| `src/Collectors.gs` | 4 媒体のデータ取得・TikTok 連携 |
| `src/Audience.gs` | 視聴者属性（年齢層・性別・フォロワー/フォロワー外）の取得・手入力 |
| `src/Metrics.gs` | 月次集計（前月比・ER・TOP 投稿） |
| `src/Ai.gs` | Claude / ChatGPT 呼び出しと**固定指示** |
| `src/Report.gs` | レポート生成・Google ドキュメント出力 |
| `src/Setup.gs` | 初期設定・定期実行・6 分制限対策のジョブキュー |
| `src/Api.gs` | 画面から呼ぶ API（すべてログイン確認付き） |
| `src/index.html` | 画面 |

## セットアップ（所要 30 分＋各 SNS の申請待ち）

### 1. GAS プロジェクトを作る

Cc の共有 Google アカウント（例：`sns@cc-…`）で作業してください。
**このアカウントがデータとレポートの持ち主になります。**個人アカウントは避けてください。

- **方法 A（手作業）**: <https://script.google.com> → 新しいプロジェクト → `src/` の各ファイルを同じ名前で作成して中身を貼り付け
  （`index.html` は「HTML」で作成）。「プロジェクトの設定」→「appsscript.json をエディタで表示」をオンにし、`src/appsscript.json` の内容で上書き。
- **方法 B（clasp）**: `npm i -g @google/clasp && clasp login` → `.clasp.json.example` を `.clasp.json` にコピーして scriptId を記入 → `clasp push`

### 2. 共通パスワードを登録して初期化

1. 「プロジェクトの設定」→「スクリプト プロパティ」に `INITIAL_PASS` = **Cc の共通パスワード（8 文字以上）** を追加
2. エディタで関数 `setup` を選んで「実行」→ 権限を許可
   - スプレッドシート「Cc SNS Hub データベース」とフォルダ「Cc SNS Hub 月次レポート」が作られます
   - パスワードはハッシュ化して保存され、`INITIAL_PASS` は自動で削除されます
   - 毎朝 6 時（データ取得）と毎月 1 日 8 時（レポート作成）の自動実行が登録されます

### 3. Web アプリとして公開

「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」
- 次のユーザーとして実行: **自分**
- アクセスできるユーザー: **全員**（パスワードで制限するため）

発行された URL をブックマークして社内に共有します（URL とパスワードは別の経路で伝えてください）。

### 4. 画面の「設定」から API キーを登録

| キー | 取得先 | 費用 |
|---|---|---|
| Claude API キー | <https://console.anthropic.com> | 従量課金（下記目安） |
| ChatGPT API キー | <https://platform.openai.com> | 従量課金 |
| YouTube Data API キー | Google Cloud Console → YouTube Data API v3 を有効化 → API キー | 無料（1 日 10,000 ユニット。7 社で 1 日約 20 ユニット） |
| Meta アクセストークン | 下記「Instagram」参照 | 無料 |
| TikTok Client Key / Secret | 下記「TikTok」参照 | 無料 |
| X Bearer Token | 任意。下記「X」参照 | 従量課金 |
| Google OAuth クライアント ID / シークレット | 下記「視聴者属性」参照（YouTube の属性を取る場合のみ） | 無料 |

登録後、「Claude 接続テスト」「ChatGPT 接続テスト」で疎通を確認してください。

### 5. クライアント 7 社を登録

ダッシュボードの「＋ クライアント追加」から登録します。
**「目的」「KPI」「トーン」を具体的に書くほど、レポートの質が上がります**（AI はここを根拠に KPI 達成状況や来月の打ち手を書きます）。

## 媒体ごとの接続準備

### Instagram（Meta Graph API）

1. 各クライアントの Instagram を **プロアカウント（ビジネス／クリエイター）** にして、Facebook ページに接続
2. Cc の **Meta ビジネスマネージャ** に、各クライアントの Facebook ページと Instagram を「パートナー」として共有してもらう
3. <https://developers.facebook.com> でアプリを作成（種類：ビジネス）し、Instagram Graph API を追加
4. ビジネスマネージャ → システムユーザーを作成 → アプリと 7 社分の資産を割り当て →
   権限 `instagram_basic` `instagram_manage_insights` `pages_show_list` `pages_read_engagement` `business_management` で**無期限トークン**を発行
5. 画面の「設定」に Meta アクセストークンとして登録
6. 各クライアントの「Instagram ビジネスアカウント ID」（17841… で始まる数字）を登録
   - Graph API エクスプローラで `me/accounts?fields=instagram_business_account,name` を実行すると確認できます

> まずは開発モードのまま試してください。他社から共有された Instagram で権限エラーが出る場合は、上記権限のアプリレビュー（Advanced Access）申請が必要です（数日〜2 週間）。TikTok と並行して早めに着手するのが安全です。

### YouTube

チャンネル ID（`UC…`）または `@ハンドル` を登録するだけで、登録者数・総再生数・動画ごとの再生/高評価/コメントを取得します。
（視聴維持率やインプレッションなどの詳細分析は、各チャンネルの YouTube Studio 権限が必要になるため次期対応）

### TikTok（Display API）

1. <https://developers.tiktok.com> で開発者登録 → アプリ作成 → **Login Kit** と **Display API** を追加
2. スコープ `user.info.basic` `user.info.profile` `user.info.stats` `video.list` を申請
3. リダイレクト URI に、画面の「設定」に表示される URL（`https://script.google.com/macros/s/…/exec`）を登録
4. **アプリ審査に 1〜2 週間かかることがあります**。審査前でも「Sandbox」に TikTok アカウントを追加すればテストできます
5. 承認後、クライアント詳細 →「基本情報・連携」→「TikTok を連携」を押し、**クライアントの TikTok アカウントでログインして許可**（初回のみ。以降は自動更新）

### X（任意）

X API は 2026 年から**従量課金**（投稿の読み取り 1 件ごとに課金）になりました。
本システムは費用を抑えるため 1 社あたり 1 日 10 投稿だけを読み取ります（7 社で月 2,000 件強）。
費用をかけたくない場合は Bearer Token を登録せず、**「手入力」タブで月末にフォロワー数と主要投稿の数字を入力**すれば、レポートに反映されます。

## 視聴者属性（年齢層・性別・フォロワー/フォロワー外）

各 SNS の公式 API で取れる範囲が違うため、媒体ごとに取り方が異なります。

| 媒体 | 年齢層・性別 | フォロワー / フォロワー外 | 投稿ごと | 取り方 |
|---|---|---|---|---|
| Instagram | ○ フォロワー／反応した人 | ○ 閲覧の割合 | ×（API 非対応） | 自動（追加設定なし。フォロワー 100 人以上が条件） |
| YouTube | ○ 視聴者 | ○ 登録者／未登録の視聴回数 | ○ 直近 10 本 | 「YouTube 詳細分析を連携」（チャンネルごとに 1 回） |
| TikTok | △ | △ | × | 公式 API 非対応のため、TikTok アプリの分析画面の % を「手入力」 |
| X | △ | — | × | 公式 API 非対応のため「手入力」 |

### YouTube 詳細分析の連携準備（1 回だけ）

1. Google Cloud Console で「YouTube Analytics API」と「YouTube Data API v3」を有効化
2. 「OAuth 同意画面」を作成（種類：外部、アプリ名：Cc SNS Hub）。スコープに `yt-analytics.readonly` と `youtube.readonly` を追加し、**公開ステータスを「本番環境」にする**
   （「テスト」のままだと 7 日ごとに連携が切れます。Google の審査を受けていない間は、ログイン時に「確認されていないアプリ」と表示されますが、「詳細」→「移動」で進めます。利用者 100 人までは審査なしで使えます）
3. 「認証情報」→「OAuth クライアント ID」（種類：ウェブアプリケーション）を作成し、承認済みリダイレクト URI に、画面の「設定」に表示される URL を登録
4. クライアント ID とシークレットを画面の「設定」に登録
5. クライアント詳細 →「基本情報・連携」→「YouTube 詳細分析を連携」を押し、**そのチャンネルを管理している Google アカウント**でログインして許可
   （ブランドアカウントのチャンネルは、ログイン後に表示されるチャンネル選択で該当チャンネルを選んでください。Cc がチャンネルの「管理者」権限をもらっていれば、Cc のアカウントで連携できます）

### 注意

- 属性は「割合（%）」で保存します。人数が少ないと各 SNS 側がデータを返さないため、開始直後は空欄になることがあります
- YouTube の属性は直近 90 日分の視聴で集計しています（短い期間だと返らないため）
- 属性は毎朝のデータ取得で更新され、月ごとに最新の値が残ります

## 月次レポートの作り方

- **自動**: 毎月 1 日 8 時に前月分を全社作成 → 通知メール → Cc 担当者が確認・微修正してクライアントへ送付
- **手動**: クライアント詳細 →「月次レポート」→ 対象月を選んで「レポートを作成」

レポートの構成は「設定」→「固定指示」で全社共通に管理しています。初期状態の構成は次のとおりです。

1. 今月のハイライト（3 行）
2. KPI 達成状況（表・◎○△判定）
3. 媒体別の結果（表＋所見）
4. 見ている人の属性（フォロワー外に届いているか・狙う層に届いているか）
5. 反応が良かった投稿 TOP3 と要因
6. 課題と原因の仮説
7. 来月の打ち手（3〜5 施策・狙い・期待する数値）
8. 担当者からのひとこと

ルールとして「データにない数値は書かない」「前月比を必ず併記」「製造業の担当者にも伝わる言葉で」を指示しています。
Cc 独自の型（例：社長向けの 1 枚サマリーを冒頭に付ける）がある場合は、固定指示を書き換えれば全社に反映されます。

### AI の動かし方（技術メモ）

- GAS は外部への通信 1 回が約 60 秒で打ち切られるため、レポートは**前半（1〜4 章）と後半（5〜8 章）を同時に生成**して結合しています
- Claude は `claude-opus-5-5`（設定で変更可）を使用します。Anthropic の安全フィルタで回答を断られた場合は、推奨の別モデルで自動的に作り直す設定（server-side fallback）を有効にしています
- 時間切れのエラーが出る場合は、設定画面で Claude モデルを `claude-sonnet-5-5` に変更してください（高速）

### AI 費用の目安

1 レポートあたり Claude 約 0.2 ドル＋ChatGPT 分析メモ数セント程度。**7 社 × 月 1 回でおおむね月 300〜500 円**です（質問機能の利用量により増減）。

## セキュリティ

- パスワードは平文で保存せず、ソルト付きハッシュ（SHA-256 × 1,000 回）で保存
- API キー・トークンは Script Properties にのみ保存し、画面には「登録済み／未登録」しか返さない
- 画面から呼べる処理はすべてログイン確認付き。自動実行の処理は「1 日 1 回／月 1 回」に制限し、AI 費用の空打ちを防止
- パスワード変更（設定画面）で全員を強制ログアウト。退職者が出たら変更してください
- データ（スプレッドシート・ドキュメント）は Cc の Google アカウント内にのみ保存されます

## 開発者向け

```bash
cd cc-sns-hub
npm test        # 月次集計ロジックのテスト（Node 20+）
clasp push      # GAS へ反映（.clasp.json が必要）
```

GAS の制約: `google.script.run` からは「末尾が `_` でない関数」がすべて呼べてしまうため、
画面用 API は `api*`（必ず `guard_` でトークン確認）に限定し、内部関数は末尾に `_` を付けています。
